# 🚀 Global IT Career Navigator (ІТ Кар'єрний Навігатор)

Інтерактивна аналітична система підтримки прийняття рішень (Decision Support System - DSS) для підбору оптимальної кар'єрної траєкторії в ІТ за багатовимірним аналізом пріоритетів та регіональних трендів ринку праці на базі **Django 5+ / 6+**.

---

## 🛠️ Стек технологій

- **Бекенд:** Python 3, Django, Django ORM (SQLite / models.JSONField), Requests.
- **Фронтенд:** HTML5, Tailwind CSS, Retro-Futuristic Gradient & Glassmorphism Palette (Deep Violet to Sunset Orange / Neon Magenta), Vanilla JavaScript.
- **Аналітика та Візуалізація:** Chart.js 4.x (Багатовимірні радарні діаграми із суворою шкалою 1–10 та кроками сітки).

---

## ✨ Ключові можливості

1. **Динамічний Селектор Регіонів:**
   - Підтримка ринків: `Global`, `USA`, `Europe`, `United Kingdom`, `Ukraine`.
   - Миттєвий перерахунок зарплатних сіток (USD, EUR, GBP) за грейдами (Junior, Middle, Senior, Lead).
   - Відображення специфічних метрик ринку (активні вакансії, річний приріст, відсоток ремоуту).

2. **5 Інтерактивних Повзунків Пріоритетів (Шкала 1–10):**
   - `1. Темп навчання та поріг входу` (Easy & Chill ↔ Hardcore Deep Theory & CS Math)
   - `2. Фінансовий вектор` (Stable Base ↔ High Senior Cap & Global Market)
   - `3. Архітектура & Логіка vs Візуал & UI` (Low-level / Backend ↔ UI/UX & Frontend)
   - `4. Масштаб компаній` (Big Enterprise & Processes ↔ Startups & Freedom)
   - `5. Рівень стресу / WLB` (Balanced & Calm ↔ High Challenge & Drive)

3. **Радарна Діаграма «Аура Пріоритетів» (Chart.js 4.x):**
   - Сувора шкала 0–10 із чіткою градацією кроків (2, 4, 6, 8, 10).
   - Перемальовується в реальному часі без затримок при русі будь-якого повзунка.
   - Оверлей-порівняння: ваш вектор проти еталонного профілю Топ-1 рекомендованого напряму.

4. **Багатокритеріальний DSS-алгоритм Матчингу:**
   - Зважена евклідова відстань у 5-вимірному просторі критеріїв.
   - Генерація персоналізованих аргументів («Чому цей трек підходить саме вам»).
   - Ранжування бази з 10 напрямків та видача **Топ-3 ідеальних напрямків** із точним відсотком збігу.

5. **Детальна Сторінка Напряму (`/career/<slug>/`):**
   - Порівняльний радар (користувач vs еталон напряму).
   - Зведена матриця зарплат по всіх 5 регіонах з інтерактивними вкладками.
   - Поетапна дорожня карта підготовки (Фази 1–4) з інтерактивними чекбоксами.
   - Переваги та виклики («Pros & Cons»).
   - Технологічний стек.

## ⚡ Швидкий старт

1. Встановіть залежності:
```bash
pip install -r requirements.txt
```

2. Застосуйте міграції бази даних:
```bash
python manage.py migrate
```

3. Заповніть базу даних початковими напрямами та кешем:
```bash
python manage.py seed_db
```

4. Запустіть сервер розробки:
```bash
python manage.py runserver
```

5. Відкрийте у браузері:
```
http://127.0.0.1:8000
```

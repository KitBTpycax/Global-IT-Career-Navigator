# 🚀 Global IT Career Navigator (ІТ Кар'єрний Навігатор)

Інтерактивна аналітична система підтримки прийняття рішень (Decision Support System - DSS) для підбору оптимальної кар'єрної траєкторії в ІТ за багатовимірним аналізом пріоритетів та регіональних трендів ринку праці.

---

## 🛠️ Стек технологій

- **Бекенд:** Python 3, Flask, Flask-SQLAlchemy, SQLite, Requests.
- **Фронтенд:** HTML5, Tailwind CSS (Deep Graphite & Noble Cherry / Crimson Red Palette), Vanilla JavaScript.
- **Аналітика та Візуалізація:** Chart.js 4.x (Багатовимірні радарні діаграми із суворою шкалою 1–10, кроками сітки та вишневим вектором).

---

## ✨ Ключові можливості

1. **Динамічний Селектор Регіонів:**
   - Підтримка ринків: `Global`, `USA`, `Europe`, `United Kingdom`, `Ukraine`.
   - Миттєвий перерахунок зарплатних сіток (USD, EUR, GBP) за грейдами (Junior, Middle, Senior, Lead).
   - Відображення специфічних метрик ринку (активні вакансії, річний приріст, відсоток ремоуту).

2. **5 Інтерактивних Повзунків Пріоритетів:**
   - `1. Темп навчання та поріг входу` (Easy & Chill ↔ Hardcore Deep Theory & CS Math)
   - `2. Фінансовий вектор` (Stable Base ↔ High Senior Cap & Global Market)
   - `3. Архітектура & Логіка vs Візуал & UI` (Low-level / Backend ↔ UI/UX & Frontend)
   - `4. Масштаб компаній` (Big Enterprise & Processes ↔ Startups & Freedom)
   - `5. Рівень стресу / WLB` (Balanced & Calm ↔ High Challenge & Drive)

3. **Радарна Діаграма «Аура Пріоритетів» (Chart.js 4.x):**
   - Сувора шкала 0–10 із чіткою градацією кроків (2, 4, 6, 8, 10).
   - Перемальовується в реальному часі без затримок при русі будь-якого повзунка.
   - Оверлей-порівняння: ваш вектор (Soft Indigo) проти еталонного профілю Топ-1 рекомендованого напряму (Subtle Slate).

4. **Багатокритеріальний DSS-алгоритм Матчингу:**
   - Зважена евклідова відстань у 5-вимірному просторі критеріїв (шкала 1–10).
   - Генерація персоналізованих аргументів («Чому це ваш матч»).
   - Ранжування бази з 10 напрямків та видача **Топ-3 ідеальних напрямків** із точним відсотком збігу (наприклад, 96%).

5. **Стійке Отримання Трендових Даних з Резервним SQLite Кешем:**
   - Передбачено підключення зовнішнього API ринку праці з автоматичним перемиканням на локальну базу даних SQLite. Додаток гарантовано працює 24/7 без падінь навіть у повному офлайні.

6. **Детальна Сторінка Напряму (`/career/<slug>`):**
   - Порівняльний радар (користувач vs напрям).
   - Зведена матриця зарплат по всіх 5 регіонах з інтерактивними вкладками.
   - Поетапна дорожня карта підготовки (Фази 1–4) з інтерактивними чекбоксами прогресу.
   - Аналіз переваг та підводних каменів («Pros & Cons»).
   - Повний перелік технологічного стеку.

---

## ⚡ Швидкий старт

1. Переконайтеся, що встановлено Python 3.10+:
```bash
python --version
```

2. Встановіть залежності (якщо ще не встановлено):
```bash
pip install -r requirements.txt
```

3. Запустіть додаток:
```bash
python app.py
```

4. Відкрийте у браузері:
```
http://127.0.0.1:5000
```
База даних SQLite `it_navigator.db` створиться та заповниться автоматично при першому старті.
